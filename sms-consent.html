What YouAt sends over SMS

YouAt sends exactly one type of SMS: a one-time 6-digit verification code, dispatched only when the end user actively taps "Continue" on the sign-in screen after entering their own phone number. No marketing, no promotions, no recurring alerts, no location updates, no third-party content.

Sample message (exact production text)

Your YouAt verification code is 123456. Reply STOP to opt out, HELP for help. Msg & data rates may apply.

How users opt in

Opt-in occurs inside the YouAt mobile app (iOS and Android). No third-party lists or purchased data are ever used.

  1. User downloads YouAt from the Apple App Store or Google Play Store.
  2. User taps "Get Started" on the onboarding screen.
  3. User is taken to the "What's your number?" screen (screenshot below).
  4. The screen displays the consent line directly beneath the heading: "We'll text you a code. Standard rates may apply."
  5. User enters their own mobile phone number and their name.
  6. User taps "Continue" to actively request an SMS verification code.
  7. Only after this explicit user action does YouAt send exactly one SMS to the number entered.

This flow satisfies the CTIA Messaging Principles & Best Practices standard for express written consent because the consent language is on the same screen as the input, the user must actively tap a button, and the message purpose is disclosed.

How users opt out

  • Reply STOP to any YouAt message. Twilio's Advanced Opt-Out blocks all future messages to that number automatically.
  • Delete their account in the app via Settings → Delete Account. The phone number is removed from our records within minutes.
  • Uninstall the app. Since all SMS is user-initiated, uninstalling stops all future messages.

How users request help

Reply HELP to receive a link to this page and a contact email. Or email support@youat.app directly.

Data handling

  • Phone numbers are stored only for the purpose of authenticating the user.
  • We never sell, share, or rent phone numbers to any third party.
  • Phone numbers are transmitted over TLS and stored on encrypted database volumes.
